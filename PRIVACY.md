# WinFlow Privacy Policy

**Last updated: August 28, 2026**

WinFlow is a Windows desktop utility developed by FEAR-Labs.

## Data collection

WinFlow does not collect, store, transmit, sell, or share personal data.

WinFlow does not use analytics, advertising, tracking technologies, telemetry services, or external servers to collect information about its users.

## Local operation

WinFlow operates locally on the user's Windows device. It uses Windows APIs only as necessary to provide its core functionality, including registering global keyboard shortcuts and managing the position and state of eligible desktop windows.

WinFlow does not read or upload the contents of user files and does not transmit information about the user's windows or activity to FEAR-Labs or third parties.

## Network communication

WinFlow does not require network communication for its core functionality and does not send user data to external services.

## Changes to this policy

If WinFlow's data practices change in a future version, this privacy policy will be updated accordingly.

## Contact

Questions about this privacy policy can be submitted through the WinFlow GitHub repository.

# Política de privacidad de WinFlow

**Última actualización: 28 de agosto de 2026**

WinFlow es una utilidad de escritorio para Windows desarrollada por FEAR-Labs.

## Recopilación de datos

WinFlow no recopila, almacena, transmite, vende ni comparte datos personales.

WinFlow no utiliza analítica, publicidad, tecnologías de seguimiento, servicios de telemetría ni servidores externos para recopilar información sobre sus usuarios.

## Funcionamiento local

WinFlow funciona localmente en el dispositivo Windows del usuario. Utiliza las API de Windows únicamente cuando es necesario para proporcionar sus funciones principales, incluido el registro de atajos de teclado globales y la administración de la posición y el estado de las ventanas de escritorio compatibles.

WinFlow no lee ni carga el contenido de los archivos del usuario y no transmite información sobre las ventanas o la actividad del usuario a FEAR-Labs ni a terceros.

## Comunicación de red

WinFlow no requiere comunicación de red para sus funciones principales y no envía datos del usuario a servicios externos.

## Cambios en esta política

Si las prácticas de datos de WinFlow cambian en una versión futura, esta política de privacidad se actualizará según corresponda.

## Contacto

Las consultas relacionadas con esta política de privacidad pueden enviarse a través del repositorio de WinFlow en GitHub.
